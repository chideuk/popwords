# 팝워즈 (PopWords)

풍선을 터뜨리며 **중국어·일본어 단어와 문장**을 외우는 무료 학습 게임입니다.
광고 없음 · 회원가입 없음 · 인터넷 없이도 사용 가능

## 바로 하기 (웹)
**https://chideuk.github.io/popwords/**

폰 브라우저로 열면 바로 플레이할 수 있고, 앱처럼 설치할 수도 있습니다.

### 앱처럼 설치하기
- **Android (크롬):** 주소 열기 → 오른쪽 위 메뉴(⋮) → **"앱 설치"** 또는 **"홈 화면에 추가"**
- **iPhone (Safari):** 주소 열기 → 공유 버튼 → **"홈 화면에 추가"**

한 번 접속해 두면 이후에는 인터넷이 없어도 실행됩니다.

## Android 앱 파일(APK) 받기
**[릴리스 페이지에서 최신 APK 다운로드](../../releases/latest)**

1. 폰에서 위 링크를 열고 `popwords-*.apk` 를 내려받습니다.
2. 파일을 열어 설치합니다. ("출처를 알 수 없는 앱 설치" 허용이 필요할 수 있습니다.)
3. Google Play Protect 경고가 나오면 **"그래도 설치"** 를 선택합니다. (Google Play 스토어를 거치지 않은 앱이라 표시되는 안내입니다.)

## 기능
- 중국어(HSK) · 일본어(JLPT) / 단어 · 문장 / 초급 · 중급 · 고급 선택
- 풍선을 터치해 터뜨리며 학습, 원어민 발음(기기 음성 기능 사용)
- 못 외운 단어는 더 자주 나오는 반복 학습, 게임 후 나온 단어 목록 확인
- 속도 조절 (느리게 / 보통 / 빠르게)
